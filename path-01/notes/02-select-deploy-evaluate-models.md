## Key concepts to capture as you read

- **Model catalog** — what model families exist on Foundry (OpenAI, Phi, Llama, Mistral, etc.), what their strengths are, what context windows they support
- **Model selection criteria** — cost, latency, context length, capability, region availability, content filter support
- **Deployment options** — pay-as-you-go vs Provisioned (PTU), global vs data-zone vs regional, deployment types
- **Deployment parameters** — model version, SKU, capacity (TPM), content filter config
- **Code deployment** — using Azure AI Foundry SDK / azure-ai-inference / openai SDK to call a deployed model
- **Evaluation** — Azure AI Evaluation SDK, built-in evaluators (relevance, coherence, groundedness, fluency, similarity), LLM-as-judge, custom evaluators
- **Monitoring** — tracing, metrics, alerts on a deployed model
